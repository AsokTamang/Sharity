## Overview

Sharity is a full-stack community platform that facilitates sustainable living through effortless sharing of unused items. It combines real-time chat, secure authentication, and a modern, responsive UI to foster meaningful connections and reduce waste.

**Why Sharity?**

This project aims to create a seamless marketplace for sharing items, supported by real-time communication and a consistent design language. The core features include:

- 🛠️ **Component Schema:** Establishes a unified styling and component structure for a cohesive UI.
- 💬 **Real-Time Chat:** Enables instant messaging between users for smooth communication.
- 🔒 **Secure Authentication:** Manages user sign-up, sign-in, and session control with JWT tokens.
- 📦 **Item Management:** Supports adding, editing, and deleting shared items with full CRUD capabilities.
- 🌱 **Community Focus:** Promotes sustainable living by encouraging reuse and sharing within a responsive platform.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** TypeScript
- **Package Manager:** Npm

### Installation

Build Sharity from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/AsokTamang/Sharity
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd Sharity
    ```

3. **Install the dependencies:**

**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### Usage

Run the project with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```

### Testing

Sharity uses the {__test_framework__} test framework. Run the test suite with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm test
```
